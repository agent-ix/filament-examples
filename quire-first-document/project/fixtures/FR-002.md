# FR-002: A sender can withdraw an invitation

## Description

The service shall let the sender of an invitation withdraw it until it is accepted.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-002-AC-1 | A withdrawn invitation is refused when it is opened. | Test |
| FR-002-AC-2 | An invitation that was already accepted cannot be withdrawn. | Test |
